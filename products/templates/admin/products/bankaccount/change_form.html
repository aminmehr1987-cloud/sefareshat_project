📚 راهنمای تعریف حساب بانکی

🔍 فیلد "حساب مرتبط" چیست؟

حساب مرتبط لینک این حساب بانکی به دفتر کل حسابداری است. هر عملیات بانکی (واریز، برداشت) به صورت خودکار در این حساب ثبت می‌شود.

💡 مثال عملی:

  • برای حساب بانک ملی → انتخاب کنید: 112001 - بانک ملی - حساب جاری
  • برای حساب بانک ملت → انتخاب کنید: 112002 - بانک ملت - حساب جاری
  • برای حساب بانک سپه → انتخاب کنید: 112003 - بانک سپه - حساب جاری

📋 مراحل تعریف حساب بانکی

  1. حساب مرتبط: یکی از حساب‌های بانکی (کد 1120xx) را انتخاب کنید
  2. بانک: نام بانک را از لیست انتخاب کنید
  3. شماره حساب: شماره حساب بانکی خود را وارد کنید
  4. شماره شبا: شماره شبای 26 رقمی (IR...) را وارد کنید
  5. نوع حساب: نوع حساب (جاری، پس‌انداز و ...) را انتخاب کنید
  6. عنوان حساب: یک نام توصیفی برای حساب وارد کنید (مثلاً: حساب اصلی شرکت)

⚠️ اگر حساب مرتبط مناسبی وجود ندارد چکار کنم؟

گزینه 1: اجرای دستور راه‌اندازی (پیشنهادی)

python manage.py setup_accounting

این دستور به صورت خودکار تمام حساب‌های استاندارد ایرانی را ایجاد می‌کند.

گزینه 2: ایجاد دستی حساب جدید

  • به صفحه افزودن حساب بروید
  • گروه حساب را انتخاب کنید: 1120 - بانک‌ها
  • کد حساب جدید تعریف کنید (مثل: 112006، 112007، ...)
  • نام حساب را وارد کنید و ذخیره کنید

📊 ساختار حساب‌های بانکی

کد نام حساب توضیح
1120 بانک‌ها (گروه) گروه اصلی حساب‌های بانکی
112001 بانک ملی - حساب جاری حساب تفصیلی
112002 بانک ملت - حساب جاری حساب تفصیلی
112003 بانک سپه - حساب جاری حساب تفصیلی
112004 بانک صادرات - حساب جاری حساب تفصیلی
112005 بانک پاسارگاد - حساب جاری حساب تفصیلی

✅ نکته مهم: بعد از ایجاد حساب بانکی، تمام واریزها و برداشت‌ها به صورت خودکار در دفتر کل ثبت می‌شوند و نیازی به ثبت دستی ندارید.

⚠️ هشدار: هر حساب بانکی فقط می‌تواند به یک حساب دفتر کل متصل باشد. پس از ایجاد، امکان تغییر حساب مرتبط وجود ندارد (فقط می‌توانید حساب جدید ایجاد کنید).
